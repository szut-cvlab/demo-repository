# 设计说明 · 视觉与低空智能实验室主页

## 视觉方向：低空测绘图版

整个主页做成一张正在标注中的低空测绘图版：坐标条、等高线图版、图例式条目，把"低空"画在版面上。

- **调性**：安静偏工具感 · 精致 · 中密度 · 庄重。
- **字体**：工程黑体（system-ui / PingFang SC）做标题正文；坐标、编号、标签、元数据一律等宽（JetBrains Mono → ui-monospace 回退）。
- **色彩**：图纸米白 `#F4F2EA` / 墨青 `#0F3A3E` / 次级 `#5D6B63` / 细线 `#D9D4C2` / 测绘橙 `#D96B2B`（仅用于编号、角标、主动作 hover）。
- **首屏骨架**：左文右图版。左侧：等宽 tag + 大标题 + 简介 + 两个动作（「研究方向」锚点滚到本页 01 板块，「联系我们」跳团队成员页）；右侧：SVG 等高线测绘图版（FIG.01，四角取景框与 Logo「框瞳」同构）。
- **页面结构**：坐标条 → 吸顶导航 → 首屏 → 01 研究方向 → 02 学术成果 → 03 科研项目 → 04 开源项目 → 05 团队成员 → 06 最新动态 → 页脚（含比例尺）。
- **动效**：① 首屏左侧元素阶梯出场（rise）；② 区块滚动出场（IntersectionObserver + data-reveal）；③ 反馈动效：导航 hover 变测绘橙、列表条目 hover 底色、按钮 hover 描边与填充反转。全部尊重 `prefers-reduced-motion`。
- **刻意不用**：渐变大色块、胶囊按钮组、每内容一张边框卡片、首字母渐变圆头像、无来源的 sky/indigo 安全色。

## 品牌符号：框瞳（Logo）

检测框四角 + 一枚瞳孔——框是"看见"的动作，瞳是"看懂"的主体，呼应「让机器看懂低空的物理世界」。双色：墨青框 `#0F3A3E` + 测绘橙瞳 `#D96B2B`，描边已转实心轮廓，任意缩放不失真。

| 文件 | 用途 |
| --- | --- |
| `logo/final-symbol.svg` | 主符号母版（256×256 方形），一般再现场景 |
| `logo/final-symbol-small.svg` | 小尺寸变体：角线加粗、瞳孔放大，≤32px 使用（`public/favicon.svg` 即由此导出） |
| `logo/final-symbol-reversed.svg` | 反白版，用于深色背景 |
| `logo/final-horizontal.svg` | 横版组合标（符号 + 实验室名），PPT 页眉、海报落款 |
| `logo/final-stacked.svg` | 竖版组合标，方形空间（宣传页、社媒头像） |
| `logo/BRAND-GUIDELINES.md` | 品牌使用规范：色值、安全间距、禁用场景 |
